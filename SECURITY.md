# Security policy

The gallery serves data files only (no code), pinned to immutable commits and verified by SHA-256 in the app before parsing. If you believe you have found a way around that model — a validator bypass, a way to serve different bytes at a pinned URL, a parsing hazard in a published entry, or anything else with security impact — please report it.

- Preferred: open a GitHub issue on this repository. If the details should stay private, say so in the issue without the details and we will arrange a private channel.

Please do not open pull requests that demonstrate an exploit against the live index. Reports are handled by the repository owner; there is no bug bounty (Beatform is a free, open-source project), but fixes and credits are prompt.
